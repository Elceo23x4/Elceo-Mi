# ELCEO Landing Visual Contract

- `01-approved-landing-concept.png` is the exact visual contract.
- No generic SaaS layout, generic cards, or default shadcn look.
- Do not paste a full-page background image from references.
- R3F is required for the hero core.
- SVG/CSS are required for exact geometry.
- GSAP is required for synchronized motion.
- Lenis is required for scroll feel.
- Embla is required for media gallery.
- Merged media gallery replaces separate picture/video sections.
- Blog/research pocket replaces old free/gallery space.
- Static layout must be accepted before animation.
- Screenshot QA is required before acceptance.
- Final exactness requires iterative screenshot correction.
- Never commit unlicensed fonts.

## Font role mapping
- Display role ↔ `03-tribes-beer-font-reference.png`.
- Bitmap/HUD role ↔ `04-offbit-font-reference.png`.
- Sans role ↔ readable interface/body fallback.
