# C6-A1 Provider Source Registry

C6-A1 delivers a canonical provider/source registry and deterministic fixture/dry-run adapter standard.

## Scope
- Registry + schema + reasoning boundary methods only.
- No live provider calls.
- No API keys or secrets.
- Live activation remains blocked by default.
- C6-A2 will expand launch asset fixture depth.

## C6-A2 fixture scenario library
C6-A2 adds deterministic launch-asset fixture scenarios only, with no live provider calls and no API keys. These scenarios are used for reasoning tests and mock contracts. C6-A3 will expand official macro adapter/schema shells.
